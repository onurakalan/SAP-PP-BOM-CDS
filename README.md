# SAP-PP-BOM-CDS
SAP Ürün Ağacı CDS 
ZPP_I_BOMItemTree CDS'i ilgili malzeme için tüm ürün ağacını( yalnızca fantomlar için) patlatır.
ZPP_I_BOMItem CDS'i ilgili malzeme için sadece bir seviye alttaki bileşenleri verir. 
Çok bileşenli malzemelerde standart BOM fonksiyonuna göre performans artışı sağlanması amaçlanmıştır.
CDS Enginering BOM'lar için çalışmamaktadır.
